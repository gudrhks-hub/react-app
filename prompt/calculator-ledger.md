# Calculator 가계부 추가 기획 문서

> 기존 [calculator.md](calculator.md)의 계산기는 그대로 유지하고, **가계부(수입·지출 리스트)** 기능을 추가한다.

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 대상 프로젝트 | `Calculator` (기존 프로젝트에 기능 추가) |
| 추가 기능 | 가계부 – 수입·지출을 Todo List처럼 등록·수정·삭제하는 리스트 |
| 계산기 연동 | 계산기의 현재 결과값을 가계부 금액으로 바로 가져온다 |
| 디자인 | 기존 글래스모피즘 디자인 유지 |
| 데이터 저장 | localStorage (Zustand `persist`) |

## 2. 기능 요구사항

### 2.1 항목 등록
- 입력 항목

| 항목 | 입력 방식 | 필수 |
| --- | --- | --- |
| 구분 | 지출 / 수입 토글 (기본: 지출) | O |
| 금액 | 숫자 입력 (0보다 커야 함, 천 단위 콤마 표시) | O |
| 카테고리 | 구분에 따라 목록이 바뀌는 선택 상자 | O |
| 날짜 | date 입력 (기본: 오늘) | O |
| 메모 | 텍스트 (최대 50자) | X |

- **계산기 값 가져오기** 버튼: 계산기에 표시된 현재 결과값을 금액 칸에 넣는다.
  - 결과값이 0 이하이거나 오류 상태면 가져오지 않는다.
  - 소수점은 반올림해 원 단위 정수로 넣는다.

### 2.2 수정
- 리스트 항목의 **수정** 버튼으로 수정 모드로 전환한다.
- 등록 항목 전부(구분, 금액, 카테고리, 날짜, 메모)를 수정할 수 있다.
- 수정 모드에서 **저장** / **닫기**를 선택한다.

### 2.3 삭제
- 항목을 리스트에서 삭제한다.
- 삭제 전에 확인 창(`삭제하시겠습니까?`)을 띄운다.

### 2.4 카테고리

| 구분 | 카테고리 |
| --- | --- |
| 지출 | 식비, 교통, 쇼핑, 생활, 문화, 의료, 기타 |
| 수입 | 급여, 용돈, 부수입, 기타 |

- 카테고리마다 색을 정해 리스트에서 작은 색 점과 배지로 표시한다.
- 구분을 바꾸면 카테고리는 해당 구분의 첫 번째 항목으로 바뀐다.

### 2.5 리스트 표시
- **월 단위**로 본다. 상단의 `◀ 2026년 10월 ▶` 버튼으로 달을 이동한다. (기본: 이번 달)
- 정렬: 날짜 최신순, 같은 날짜는 등록 최신순
- 각 항목 표시: 날짜, 카테고리, 메모, 금액
  - 지출: `-12,000원` (분홍/빨강 계열)
  - 수입: `+50,000원` (초록 계열)
- 해당 달에 항목이 없으면 `이번 달 내역이 없습니다`를 표시한다.

### 2.6 합계

| 합계 | 내용 |
| --- | --- |
| 전체 합계 | 등록된 모든 항목의 총수입, 총지출, 잔액(수입 − 지출) |
| 월 합계 | 선택한 달의 수입, 지출, 잔액 |
| 카테고리별 합계 | 선택한 달의 지출을 카테고리별로 합산, 금액 큰 순서로 막대(비율)와 함께 표시 |

### 2.7 데이터 유지
- 가계부 데이터는 localStorage에 저장해 새로고침 후에도 유지한다.
- 계산기의 기록·메모리와 저장 key를 분리한다.

## 3. 데이터 구조

```js
// 가계부 항목
{
  id: string,                    // crypto.randomUUID()
  type: 'expense' | 'income',    // 지출 / 수입
  amount: number,                // 원 단위 정수
  category: string,              // 'food' | 'transport' | ... (카테고리 key)
  date: string,                  // 'YYYY-MM-DD'
  memo: string,                  // 메모 (없으면 '')
  createdAt: number,             // 등록 시각
}
```

## 4. 화면 구성

- 넓은 화면: 계산기 오른쪽 패널의 탭을 **[가계부] [기록] [메모리]** 3개로 늘린다. 가계부가 들어가도록 패널 너비를 넓힌다.
- 좁은 화면(모바일): 기존처럼 버튼으로 패널을 열고, 같은 3개 탭을 사용한다.

```

│ MC MR M+ M- MS       │  │ 전체  수입 +3,000,000  지출 -820,000   │

│ │  │  │  │  │        │  │                                     │
```

## 6. Store 설계 (Zustand)

```js
// src/stores/ledgerStore.js
{
  entries: [],
  addEntry({ type, amount, category, date, memo }),
  updateEntry(id, { type, amount, category, date, memo }),
  deleteEntry(id),
}
```

- `persist` 미들웨어로 localStorage에 저장한다. (key: `calculator-ledger`)
- 보고 있는 달(선택 월)은 화면 상태로만 관리하고 저장하지 않는다.
- 계산기 값 가져오기는 기존 `calcStore`의 `display`, `error`를 읽어서 처리한다.

## 7. 개발 순서

1. `utils/category.js`, `utils/format.js` 금액 표시 함수
2. `service/ledgerService.js` (생성·검증·월 필터·정렬·합계)
3. `stores/ledgerStore.js`
4. 등록 폼 → 리스트·항목(수정/삭제) → 월 선택 → 합계 → 카테고리별 합계 순서로 컴포넌트 구현
5. `SidePanel`에 가계부 탭 추가, 패널 너비 조정
6. 계산기 값 가져오기 연동
7. 동작 확인 (등록/수정/삭제, 수입·지출 전환, 월 이동, 합계, 카테고리별 합계, 계산기 연동, 새로고침 유지, 모바일)
